# Privacy Policy Draft

This draft is not legal advice. Review with counsel before publishing.

## Data We Process

Velt processes merchant account information, store metadata, catalog data, search queries, click events, API usage metadata, and integration credentials required to provide semantic product search and analytics.

## How We Use Data

We use merchant data to ingest catalogs, build search indexes, serve storefront search results, generate merchant analytics, secure the service, prevent abuse, and provide support.

## Data Sharing

We do not sell merchant catalog or shopper query data. We share data only with infrastructure providers needed to operate the service, legal or security authorities when required, and integrations authorized by the merchant.

## Retention

Catalog, query, click, and integration data are retained while the merchant account is active unless a shorter retention period is configured or deletion is requested.

## Security

We use access controls, hashed API keys, encrypted integration tokens, production secret validation, network restrictions, backups, monitoring, and incident response procedures to protect the service.

## Merchant Controls

Merchants may request export, correction, or deletion of account and catalog data. Deletion may require removing derived search indexes and backups according to the retention policy.
